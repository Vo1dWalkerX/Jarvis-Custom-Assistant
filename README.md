# 🤖 J.A.R.V.I.S. Custom Assistant

**Just A Rather Very Intelligent System** — ваш персональный голосовой ассистент, который не просто отвечает на вопросы, но и управляет вашей системой.

Создан для тех, кто хочет, чтобы их компьютер слушался не только мышки и клавиатуры, но и голоса. Работает на **Linux (Arch/Ubuntu)** и **Windows**.

---

## ✨ Полный список возможностей

### 🧠 Ядро и ИИ
*   **Умный диалог:** Работа с LLM через Groq (модель `allam-2-7b` или любая другая). Ассистент отвечает кратко, по делу и без лишнего пафоса.
*   **Голосовая активация:** Ожидание слова «Джарвис» (или «Джервис», «Жарвис») через офлайн-модель Vosk.
*   **Распознавание речи:** Команды и вопросы распознаются через Whisper (Groq), что позволяет задавать сложные вопросы.
*   **История диалога:** Джарвис помнит контекст (до 20 сообщений), но сбрасывает его при долгом простое (15 минут).
*   **Запрет на цифры:** В промпте жестко прописано правило: «Все числа только словами», чтобы озвучка не превращалась в «один ноль ноль».

### 🖥️ Управление системой (Linux и Windows)
*   **Окна:** «Сверни все окна», «Закрой все окна» (с защитой окна самого Джарвиса), «Закрой {приложение}» (с поддержкой алиасов).
*   **Питание:** «Выключи компьютер», «Перезагрузка», «Спящий режим», «Заблокируй компьютер».
*   **Громкость и яркость:** «Громче», «Тише», «Без звука», «Ярче», «Темнее».
*   **Музыка:** Управление плеером («Пауза», «Играй», «Следующий трек», «Предыдущий трек»).
*   **Приложения:** Открытие приложений по имени или алиасу («Открой браузер», «Открой телегу»).

### 📝 Полезные инструменты
*   **Погода:** «Какая погода в Москве?» (запрос к wttr.in).
*   **Таймеры:** «Поставь таймер на пять минут» (понимает числа словами и цифрами).
*   **Заметки:** 
    *   *«Запомни купить молоко»* (можно надиктовать голосом).
    *   *«Вспомни вторую заметку»*.
    *   *«Забудь третью заметку»*.
    *   *«Что в заметках?»* (читает первые пять).
*   **Скриншоты:** «Сделай скриншот» (через grim/scrot или pyautogui).
*   **Сброс контекста:** «Забудь контекст», «Очисти память».

### 🔌 Плагины и расширения
*   **Свои команды:** В папке `plugins/` можно создавать `.py` файлы с собственными командами. Джарвис автоматически подхватит их при запуске.
*   **Алиасы приложений:** В настройках можно указать, что «телега» — это Telegram, а «браузер» — это Chrome.

### 🎨 Интерфейс (CustomTkinter)
*   **Кастомизация:** Светлая/тёмная тема, смена цветов фона, кнопок и текста.
*   **Управление:** Кнопки «Включить/Выключить» (пауза микрофона), «Логи вкл/выкл», «Настройки», «Команды», «Выйти».
*   **Настройки ИИ:** Выбор провайдера, ввод ключа, запрос доступных моделей, настройка температуры и `max_tokens`.

### 🛡️ Стабильность
*   **`crash.log`:** Если скрипт падает с ошибкой, она записывается в лог с датой и временем.
*   **Проверка версий:** При запуске `jarvis.py` и `ui.py` сверяют версии, чтобы избежать несовместимости.
*   **Хоткей:** Глобальная активация `Ctrl+Alt+J` (через портал, на Linux).

## 🚀 Установка (всё включено)

Джарвис поставляется с **единым установщиком**, который сам скачает модели, библиотеки и настроит окружение. 

### 🐧 Linux (Arch / Ubuntu)
1.  Скачайте файл `jarvis_setup.py` из этого репозитория.
2.  Откройте терминал и запустите установщик:
    ```bash
    sudo python jarvis_setup.py
    ```
    *(⚠️ **ВАЖНО:** Установщик требует `sudo` для установки системных пакетов. Если вы запустите его от `root`, ярлыки создадутся в `/root/`. Запускайте от `sudo`, тогда установщик вернет права вашему пользователю.)*
3.  После завершения запустите:
    ```bash
    ./jarvis-app/venv/bin/python ./jarvis-app/jarvis.pyc
    ```

### 🪟 Windows
1.  Скачайте файл `jarvis_setup.py` из этого репозитория.
2.  Откройте командную строку (`cmd` или PowerShell) и запустите:
    ```cmd
    python jarvis_setup.py
    ```
3.  Дождитесь завершения (установщик сам скачает Piper и модели).
4.  Запустите:
    ```cmd
    jarvis-app\venv\Scripts\python.exe jarvis-app\jarvis.pyc
    ```

## ⚙️ Настройка

При первом запуске откройте окно **«Настройки»** и укажите ваш **API-ключ** (например, от Groq) во вкладке «ИИ». Без этого Джарвис не сможет отвечать на вопросы.
